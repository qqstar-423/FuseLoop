# 中文准备材料：仅用于翻译和连通性测试

以下是合成记录，没有在 NPU 上执行，不代表真实算子性能。

评测口径采用 cann-bench 的 kernel_details，汇总每个 kernel 执行耗时的中位数，不包含 kernel 之间的间隔。baseline、speedup、HAP、总分均使用工具原值。profiling 的合成结论是：中间结果写回和读取可能产生多余流量；这不足以证明单 kernel 更快，需要同口径实测其他融合方案。
